# The JB11 Repository

A third-party Jellyfin plugin repository.

## Adding to Jellyfin

1. Go to **Dashboard → Plugins → Repositories**
2. Click **Add** and enter:
   - **Name:** `The JB11 Repository`
   - **URL:** `https://raw.githubusercontent.com/jeremiahbeasley/jb11-jellyfin-repository/main/manifest.json`
3. Click **Save**
4. Go to **Catalog** to browse and install plugins

## Available Plugins

| Plugin | Category | Description |
|--------|----------|-------------|
| [Library Importer](https://github.com/jeremiahbeasley/jellyfin-plugin-libraryimporter) | Metadata | Bulk-import movie/TV metadata from disk, TMDB, and TVDB with scheduled scans and custom overrides |
